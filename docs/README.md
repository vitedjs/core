# Vited Core

Vited Core integrates documentation sites with Vite. It discovers Markdown and
MDX documents, transforms them into pages, and renders them with a theme.

Get started with the [installation guide](./installation.md), configure your
site in the [configuration reference](./configuration.md), and learn about
document structure in the [guide](./guide/README.md).

See the project [README](../README.md) for more information.
