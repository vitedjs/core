# 编写文档

在项目根目录创建 `docs` 目录并添加文档。Vited 会把 Markdown（`.md`）和 MDX（`.mdx`）
文件作为页面，子目录名称会成为路由片段。

- [文件格式](./file-format.zh.md)：路由、多语言，以及哪些文件会成为页面。
- [元数据](./metadata.zh.md)：页面的 frontmatter 字段。
- [代码片段](./code-snippets.zh.md)：如何书写代码块。
- [React 组件](./react-components.zh.mdx)：在 MDX 中渲染组件。

所有 Vited 专属选项和 Vite 配置请参阅[配置文档](../configuration.zh.md)。
