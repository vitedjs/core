# React components

`.mdx` documents are compiled to React components, so they support standard
JavaScript imports. Import a component from a project source file, then use it
as a JSX element in the document:

```mdx
import Callout from '../../examples/mdx/callout.tsx';

<Callout>This message is rendered by a React component.</Callout>
```

The import path is relative to this MDX file. In your project, point it to the
component's location and make sure any packages used by that component are
installed in your Vite project.
