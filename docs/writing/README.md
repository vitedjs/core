# Writing documents

Create a `docs` directory under the project root and add documents to it. Vited
turns Markdown (`.md`) and MDX (`.mdx`) files into pages, and nested directories
become route segments.

- [File format](./file-format.md) covers routes, locales, and which files become
  pages.
- [Metadata](./metadata.md) lists the frontmatter fields of a page.
- [Code snippets](./code-snippets.md) shows how to write code blocks.
- [React components](./react-components.mdx) renders a component from MDX.

See the [configuration reference](../configuration.md) for all Vited-specific
and Vite options.
