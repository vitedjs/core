# 在 MDX 中使用 React 组件

MDX 支持标准 JavaScript 导入语法。先从项目源码文件导入组件，再像 JSX
元素一样在文档中使用：

```mdx
import Callout from '../../examples/mdx/Callout.tsx';

<Callout>这段内容由 React 组件渲染。</Callout>
```

导入路径相对于当前 MDX 文件。在自己的项目中，请将路径指向组件所在位置，
并确保 Vite 项目已安装该组件依赖的所有软件包。
